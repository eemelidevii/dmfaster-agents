# DM Faster agent plugin

This dual-host plugin bundles the canonical DM Faster skill and a version-pinned local stdio MCP server definition for Codex and Claude Code.

The current release exposes exactly seven read-only tools. It cannot create or edit campaigns, launch or pause sending, send replies, schedule work, book meetings, or spend credits.

## Release status

The plugin source is a distribution release candidate. It becomes installable for users only after all four version-pinned `@dmfaster` packages are published and the browser-authorization backend plus migration 0170 are deployed.

Do not point users at the private monorepo as a public marketplace. Publish this plugin directory through an approved public marketplace or plugin listing after package, privacy, and platform review.

Repository maintainers must follow the [agent distribution release runbook](../../docs/runbooks/agent-distribution-release.md). Package publication and plugin publication are separate approved releases.

## Authentication

Node.js 24 and macOS Keychain or Linux Secret Service are required. Windows is not supported in this release.

```bash
npx --yes @dmfaster/cli@0.1.0 auth login --json
```

The human signs in with their normal DM Faster account, compares the browser and CLI confirmation codes, reviews the workspace and read scopes, and personally approves or denies the request. The CLI and MCP server then share the operating-system credential.

## Development validation

- Codex manifest: `.codex-plugin/plugin.json`
- Shared MCP map: `.mcp.json`
- Claude manifest: `.claude-plugin/plugin.json`
- Canonical shared skill: `skills/dmfaster/`

Use the repository checks before packaging. Before the pinned npm package exists, validate the complete plugin manifests but test live source-checkout behavior with the built MCP server configured separately and the nested `skills/dmfaster/` directory; loading the canonical plugin would correctly try the unavailable public package. After publication, Claude Code can load the complete directory with `claude --plugin-dir ./plugins/dmfaster`, and Codex can use an approved marketplace entry generated by its supported plugin flow.
